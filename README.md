# DevOps Lab Experiments

This repository contains 12 DevOps lab experiments covering source code management, CI/CD, containerization, orchestration, and automated testing. It includes experiment documentation, source code, execution steps, and screenshots where applicable.

## 📚 Experiments

| Week | Experiment | Technologies |
|---|---|---|
| Week 01 | HTML and JavaScript Event Registration Form | HTML, JavaScript |
| Week 02 | Git and GitHub Fundamentals | Git, GitHub |
| Week 03 | Practice Source Code Management on GitHub | Git, GitHub |
| Week 04 | Install and Configure Jenkins on Windows | Jenkins |
| Week 05 | Integrate a Java Project with Jenkins | Java, Jenkins, GitHub |
| Week 06 | Practice Basic Docker Commands | Docker |
| Week 07 | Run a Java Application in a Docker Container | Java, Docker |
| Week 08 | Integrate Kubernetes with Docker Desktop | Docker, Kubernetes |
| Week 09 | Automate Running a Containerized Application | Docker, Kubernetes |
| Week 10 | Install and Explore Selenium | Selenium, Node.js, JavaScript |
| Week 11 | Test a JavaScript Registration Form Using Selenium | HTML, JavaScript, Selenium |
| Week 12 | Node.js Registration Application with Docker and Selenium | Node.js, Express.js, Docker, Selenium |

## 🎯 Objectives

- Learn source code management using Git and GitHub.
- Understand CI/CD using Jenkins.
- Practice Docker commands and containerization.
- Explore Kubernetes deployments, pods, and services.
- Automate browser testing using Selenium.
- Integrate Node.js applications with Docker and automated tests.

## 🛠️ Technologies Used

- HTML and JavaScript

- Java
- Jenkins
- Docker and Docker Desktop
- Kubernetes and kubectl
- Node.js and Express.js
- Selenium WebDriver

## 🚀 Getting Started

Clone the repository using the following commands:

```bash
git clone https://github.com/digullagopichand/DevOps-Lab-Experiments.git
cd DevOps-Lab-Experiments
```

Open the required week's folder and follow the experiment instructions. Install the necessary tools and dependencies before executing the programs.
