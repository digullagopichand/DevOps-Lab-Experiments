**# Week 1 – Simple Event Registration Form**



**## Aim**

**To create a basic event registration form using HTML and JavaScript.**



**## Technologies Used**

**- HTML**

**- JavaScript**

**- Web Browser**

**- Visual Studio Code**



**## Experiment Description**

**This experiment creates a basic event registration form. Users can enter their full name, email address, phone number, and select an event.**



**The form validates the input and displays a registration success message when valid details are submitted.**



**## Features**

**- Full name input**

**- Email validation**

**- Ten-digit phone number validation**

**- Event selection:**

&#x20; **- Workshop**

&#x20; **- Seminar**

&#x20; **- Conference**

**- Registration button**

**- JavaScript validation and alert message**



**## Files Included**

**- `index.html` – Source code of the event registration form**

**- `experiment-record.pdf` – Lab experiment record**

**- `images/` – Execution screenshots**



**## How to Execute**

**1. Open the project folder in Visual Studio Code.**

**2. Open `index.html`.**

**3. Save the file.**

**4. Open `index.html` in a web browser.**

**5. Enter your details and select an event.**

**6. Click the \*\*Register\*\* button.**

**7. Check the alert message displayed by the browser.**



**## Expected Output**

**An event registration form containing fields for full name, email, phone number, and event selection.**



**When valid details are submitted, the browser displays:**



**`Registration Successful!`**



**## Result**

**A basic event registration form using HTML and JavaScript is created and tested.**
